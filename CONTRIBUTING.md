
# Guidelines for interacting with the Mallob Repository

Here we list some guidelines on interacting with and contributing to the Mallob project. Please follow these guidelines when reaching out to us.

## Issues, Bug Reports, Feature Requests

You can use Github's issue tracking system to submit a bug report, technical issue / question, or feature request. Alternatively, you can always [contact us via email](https://satres.kikit.kit.edu/schreiber/) with your request.

We ask you to note and respect that the publicly funded researchers maintaining this project provide a non-binding service, free of charge, to consider your request. We expect in return that some degree of human effort from the other side is invested as well. In particular, we do not accept any low-effort AI-generated requests. If your request is AI assisted / driven, please let us know explicitly and append the output produced by AI as applicable.

## Contributing Code

We welcome small PRs (via Github or via email with patch file) that fix some issue or provide a minor new feature. Please do note that in doing so, you accept that the code you submit is published under Mallob's current and future licenses and that such a contribution does **not** make you an official (co-)author or a copyright (co-)holder of the project.

When contributing code, please ensure that the diff in terms of lines changed is as small as possible. This especially concerns auto formatting tools, which can cause huge diffs and should therefore be avoided on already existing files.
